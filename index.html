When you run the installer for the first time, Windows might show a blue/yellow warning saying "Windows protected your PC" or "Microsoft Defender SmartScreen prevented an unrecognized app". This is normal.

About DKU - Docs Editor

“DKU - Docs Editor Makes Your Day Easy!”

One desktop app for print shops, cyber cafés, and photo studios — edit, arrange, print photos, documents, ID cards, and PDFs in minutes.

What’s inside

  • Photos: Standard-size crops (Passport, Stamp, Visa…) or custom sizes, AI background cutout, look controls, borders, and stackable layers.
  • Documents: Auto edge-detect with perspective crop, auto-enhance with colour-look presets, one-click Reset after the enhance, size templates (Aadhaar, PAN, Passport…).
  • Scanner: Scan with your installed scanner driver, auto-crop pages, save as PDF or images, and pull text out with OCR.
  • Combine on Page: Fit multiple photos/documents on A4, Letter, or custom sheets with gaps, margins, and order — reuse partially printed paper.
  • PDF Toolkit: Merge, split, compress, page numbers, header/footer, text/image additions, password removal, Word/Excel/images conversion.
  • ID (PVC) Cards: Front + back auto-crops at exact card size, manual crop with face area, signature cleanup, live templates, paper-sheet layout, one-click Epson Photo+ hand-off.
  • Print & Export: Print directly, or save as PDF/PNG/JPEG at the exact file size you need.

Why shops love it

  • Comfortable dark/light UI with fast tab switching
  • Live preview while you edit — full quality on save or print
  • Smooth and responsive even with large files
  • Undo/Redo everywhere; presets and settings remembered
